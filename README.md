# FORZA

Web de rutinas de gimnasio personalizables.

### Generador de rutinas
- Grupo muscular
- Objetivo: hipertrofia, fuerza o definición
- Nivel: principiante, intermedio o avanzado
- 2 a 5 días por semana
- Biblioteca amplia de ejercicios
- Evita repetir ejercicios entre días cuando hay suficientes opciones
- Genera una combinación diferente cada vez

## Publicar en GitHub Pages
Sube `index.html`, `style.css` y `script.js` al repositorio y configura GitHub Pages desde la rama `principal` y la carpeta `/ (root)`.
